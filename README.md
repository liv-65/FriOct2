# 片段存档
启动: 双击 start.command (自动打开 http://localhost:8810 )。关闭终端窗口即停止。
粘贴 YouTube 链接 -> 自动下载视频、封面、文字说明 -> 按 library/赛季/日期/ 放好 -> 记入 clips.csv。
clips.csv 是总表, 可直接用 Numbers / Excel 打开。删除的片段先移到 library/.trash/ 。
整个文件夹可以随意搬到别处, 里面全部使用相对路径。
依赖: python3、yt-dlp、ffmpeg。球员名称等在 config.json 里改。

## NHL 官方数据
config.json 里的 nhl_player_id 是球员编号(Karlsson = 8474578)。网页里点“同步官方数据”, 会读取所选赛季该球员的每个进球和助攻
(含谁进球、谁助攻、第几节几分几秒、多打少/少打多), 并和已存档的片段对照, 一键下载缺少的官方片段。
数据来自 NHL 网站自己使用的公开接口(没有官方文档, 以后可能改动); 官方视频版权属于 NHL, 请只作个人资料存档。

## 内容摘要
- 进球/助攻: 用官方数据自动生成一句中文摘要(不经过 AI)。
- 采访: 先在本机用 whisper 转写英文逐字稿(不联网), 再把【文字】发给云端模型总结成“摘要 + 3 条要点”(视频本身不上传)。
  需要密钥: 复制 secrets.env.example 为 secrets.env, 填入 ANTHROPIC_API_KEY (或 LLM_API_KEY), 重启。没有密钥时其他功能照常。
- 摘要可以手改, 改过的会标为“手写”。英文逐字稿保存在视频旁边(.en.txt), 网页里可展开核对。

## 照片 (来自 X)
粘贴 X(推特)帖子链接, 如果帖子里是照片, 会把整组原图下载到 library/照片/_待筛选/, 在网页的“照片”页逐张选“选入”或“排除”:
选入 -> library/照片/赛季/日期/ ; 排除 -> library/照片/_已排除/ (随时可以改回来)。照片信息记在 photos.csv。
读取帖子用的是 X 自己的公开嵌入接口(不需要登录, 但没有官方文档, 以后可能改动)。程序不会通过脸来认人, 只能提示“帖子文字/图片说明里提到了他”。
照片版权属于球队和摄影师, 请只作个人资料存档。

## 起始日期
config.json 里的 archive_start (现在是 2026-09-29): 只收录这一天(含)之后的内容。
- 官方数据同步: 不读取这之前的比赛。
- 粘贴视频/X 照片链接: 发布日期早于它的会自动跳过(视频在下载前就跳过); 想收更早的, 把 archive_start 改早, 或改成空字符串 "" 取消限制。
- 添加时如果明确填了更早的比赛日期, 会被拒绝。已经在存档里的内容不受影响, 你手动修改片段日期也不受限制。

## 比赛页 (按场归组)
网页的“比赛”页: 一场比赛一页, 包含 比分、Karlsson 本场数据、全队数据对比(射门/冲撞/封堵/失误/抢断/罚时/多打少/发球)、进球时间线、
出场名单和看台名单、三星, 以及这场比赛的 进球/助攻视频、赛前/赛后采访、照片(阵容图/数据表图)。
数据来自 NHL 官方公开接口: 在网页里点“同步官方数据”(会同时读取比赛明细, 只读取起始日期之后已结束的比赛)。
视频和照片按日期自动归到对应的比赛; 采访允许归到前一天的比赛(赛后第二天才发的采访)。归错了可以在片段/照片的详情里改“所属比赛”。
采访的“赛前/赛后”按标题关键词猜, 猜不到的显示为“还没标注”, 可手动选择。config.json 里的 nhl_team 是球队缩写(PIT)。

## 阵容变动
比赛详情页会和存档里的上一场比较出场名单: 新上场(并说明上一场是看台还是不在名单里)、本场没上场(看台, 或不在名单里)、
同位置的对应关系、首发门将变化、上场时间很短的球员。官方数据只有“出场/看台”, 没有伤病或下放原因, 页面不会猜原因。
受起始日期限制, 存档里最早的一场没有上一场可比。

## 阵容分组(手动选线)
官方数据只有“谁上场了”, 没有“谁在哪条线”。在比赛详情页的“阵容分组”里手动填: 前锋 4 条线(左边锋/中锋/右边锋)、后卫 3 对、门将首发/替补。
每个格子只能选这场实际上场的人, 一个人只能放一个位置。球队发的阵容图(类型选“阵容”的照片)会显示在旁边, 对着图填。
“预填”按钮是按位置和上场时间猜的一版, 只是起点, 请核对。保存在 lines.json (不会被官方数据同步覆盖)。
两场都填过之后, “与上一场相比”里会显示线路层面的变化(哪个位置换了人、哪些球员换了位置)。
阵容分组有两种填法, 可随时切换: “按球员选”(列出 NHL 官方出场名单里的每个球员, 给每人选线路, 选已有人的位置会自动互换) 和 “按位置选”(给每个位置选球员)。

## 从上一场复制阵容分组
给一场比赛填阵容分组时, 如果上一场已经填过, 打开编辑会自动把上一场的分组复制过来, 再按这场的实际情况检查, 对不上的留空并写明原因:
没上场的; 位置组对不上的(前锋/后卫/门将); 上一场填在中锋格子、这场不是中锋的; 上一场填在边锋格子、这场像是改打中锋的。
“是不是中锋”用这场的争球次数判断(争球最多的 4 名前锋, 且至少 3 次), 所以需要同步官方数据时一并读取的争球记录(play-by-play)。
左、右边锋无法从数据区分, 保留上一场的左右。编辑时也可以随时点“复制上一场的阵容”重新复制。

## 卡尔松和谁一起打球 (比赛页右栏)
比赛详情页分左右两栏: 左边是阵容分组(手动填), 右边是“这位球员和谁一起打球”: 总上冰时间(5 对 5 / 多打少 / 少打多)、
后卫搭档、同时在冰上的前锋(全部 / 5 对 5 / 多打少 / 少打多)、5 对 5 时最常见的前锋三人组。
数据来自 NHL 官方逐次上冰记录(shift chart), 在“同步官方数据”时一并读取并存进 games.json, 逐秒统计谁和他同时在冰上(不含门将)。
5 对 5 / 多打少 / 少打多按冰上双方滑冰人数区分, 比赛中撤门将换人时可能不准。已同步过但还没有这项数据的比赛, 再点一次“同步官方数据”会补上。
